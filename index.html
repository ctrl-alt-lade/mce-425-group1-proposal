Smart Thermal Management System for Server Racks

Closed-Loop Environmental Control & Real-Time Telemetry Prototype

Executive Summary:

Data centers suffer hardware degradation when internal rack temperatures exceed safe limits. This project builds a miniature, self-regulating server rack enclosure powered by a Raspberry Pi 4 (1GB) that monitors internal thermodynamics and actuates dual 12V exhaust fans via hysteresis control while streaming live metrics to a local FastAPI dashboard.

CORE: RASPBERRY PI 4 (1GB) ₦149,500 TOTAL BOM

Project Aim & Core Objectives

Simulating Modern Data-Center HVAC Principles

Primary Aim

To design and implement an automated, closed-loop thermal management system that monitors and regulates the internal environment of a miniaturized server rack enclosure—demonstrating real-time hardware actuation, optical power isolation, and asynchronous web telemetry.

Objective 01 • Sensing

Hysteresis Regulation

Poll temperature and humidity via a digital DHT22 sensor. Use a deadband hysteresis loop (ON at 32°C, OFF at 28°C) to eliminate relay chattering.

Objective 02 • Power

Isolated 12V Switching

Bridge the Pi’s 3.3V GPIO with a dedicated 12V 5A rail using an optoisolated 4-channel relay to drive dual fans without voltage brownouts.

Objective 03 • Telemetry

FastAPI & MQTT Portal

Decouple hardware polling from visualization using a local MQTT broker and FastAPI web dashboard with live manual override controls.

Hysteresis Control & Fault Tolerance

Preventing Relay Chattering & Dropped Sensor Packets

In [1]: Python Deadband Hysteresis Loop (30°C ± 2°C)

TARGET_TEMP = 30.0  # °C Setpoint
DEADBAND    = 2.0   # ±2.0°C Hysteresis Margin

try:
    temp, hum = dht22.read_retry()
    if temp >= (TARGET_TEMP + DEADBAND):
        relay_fans.on()   # Trigger ON at >= 32.0°C
    elif temp <= (TARGET_TEMP - DEADBAND):
        relay_fans.off()  # Trigger OFF at <= 28.0°C
except ChecksumError:
    retain_previous_state() # Ignore glitch

1. Mechanical Relay Protection

A naive if temp > 30 check causes rapid clicking ("chattering") around 29.9°C–30.1°C. Our 4°C deadband window preserves relay contact life.

2. Exception-Safe Polling

Transient timing glitches on the DHT22 single-wire bus are caught cleanly, retaining the last valid state in memory without crashing the loop.
